Customer prerequisites checklist

Give this page to the customer's cloud, network, DNS and security contacts before the install call. Every item is something the installer cannot do for you, or something that makes it stop part-way. If every box is ticked, the install runs in one go (about 1.5-2 hours, then a hands-off finish).

3. GPU capacity (the step that fails most often)

The models need 10 GPU servers (5 models x 2 replicas). Customers run 2 x p4d.24xlarge (8x A100 each); the pool can grow to 4.

5. Network and egress

The Straiker servers sit in a private network with no direct line to the internet. To install and upgrade, they must reach out (egress) to a few named addresses over HTTPS (port 443). Nobody needs to reach in, except your own users opening the website. Your network team opens these doors in the firewall, proxy or AWS NAT gateway (the shared exit for private servers).

Where to run the checks: from a machine behind the same firewall or proxy as the cluster: best a small temporary EC2 test server in the private subnet (open it with AWS Session Manager, delete it afterwards). A laptop on another network can pass what the cluster fails. Reading results: any answer (even 403 or 404) means the door is open. BLOCKED (code 000) means a firewall dropped it, the name did not resolve, or a device that inspects encrypted traffic rejected it (tell us if you inspect HTTPS).

First define the checker once on the test machine:

chk(){ for h in "$@"; do c=$(curl -s -o /dev/null -m 10 -w '%{http_code}' "https://$h/"); [ "$c" = 000 ] && echo "BLOCKED  $h" || echo "OK ($c)  $h"; done; }
R=<region>; A=<account-id>; D=<your-domain>
